# gastown-tower

## Agent skills

### Issue tracker

Issues and PRDs are tracked as GitHub issues (Ljferrer/gastown-tower) via the `gh` CLI. This repo uses the **`Ljferrer`** GitHub account (personal) — `gh` has two accounts and the active one is a global toggle, so run `gh auth switch --user Ljferrer` first. Repo auto-detection works (gh resolves the `Ljf.github.com` SSH alias). See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical labels (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
